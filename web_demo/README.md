# RoadGuard browser demo

This folder contains the static browser demonstration for the RoadGuard AI pothole-detection project.

```bash
npm start
```

Open `http://localhost:3000`. The demo shows a real pothole road image, a muted autoplay loop video with an animated scan and green pothole marking, and an interactive **Detect pothole** control that ends with **“Pothole detected — review required”**.

The UI is a prototype communication layer. The training and measured evaluation workflow is in `../notebooks/AI_Potholes_Detection.ipynb`.
